##  Sobre o Treinamento

Este repositório reúne os materiais, scripts e instruções utilizados no **Treinamento em Processamento de Dados Genômicos de Elementos Ultraconservados (UCEs)**.

O objetivo do curso é capacitar os participantes nos fundamentos da bioinformática aplicada à sistemática molecular, com foco na utilização do pipeline **Phyluce** e ferramentas complementares para análise filogenômica.

---

##  Objetivos

- Compreender o conceito e aplicação de UCEs em sistemática
- Organizar dados paired-end em ambiente Linux
- Executar controle de qualidade (QC)
- Processar dados no pipeline Phyluce
- Submeter e monitorar jobs no GRID-UNESP
- Interpretar árvores filogenéticas resultantes

---

##  Ferramentas Utilizadas

- Terminal Linux (Bash)
- Git e GitHub para controle de versões
- Ambiente Conda
- Phyluce
- Acesso remoto via SSH / PuTTY
- Execução em ambiente HPC (GRID-UNESP)
